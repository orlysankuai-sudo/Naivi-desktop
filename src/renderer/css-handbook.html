套用與復原

設定 → 外觀 → 自訂整個應用程式的 CSS → 儲存。最多 20,000 字元，儲存在本機。按 Ctrl + Shift + Backspace 可清除 CSS，即使設定入口被隱藏仍有效。不要遮住確認、取消或錯誤訊息。

主題變數

變數用途
--bg / --text / --muted背景、正文、次要文字
--soft / --solid / --panel / --line柔和背景、實色面板、玻璃面板、邊線
--reading-font / --reading-size / --ui-size閱讀字體、閱讀字級、介面字級

部分變數由設定以行內樣式寫入，覆寫時加 !important。強調色使用內建五款選項。

:root { --reading-size: 16px !important; }
html[data-theme="dark"] { --panel: rgba(20,24,32,.8) !important; }
.message-content { line-height: 1.9; }
.composer { border-radius: 18px; }

選擇器內容

DICK Markdown

支援標題、粗體、斜體、清單、引用、程式區塊、HTTPS 連結及表格。表格容忍模型在每一行之間插入空行。

| 項目 | 狀態 |
| --- | --- |
| 檢查 | 完成 |

沿用 Classic DICK 的安全提示框子集（請寫在單行）：

<div class="tip-box">補充說明。</div>
<div class="status-box box-question">尚待確認的問題。</div>

另有 warning-box、box-topic、box-related、box-done、box-right、box-urgent、box-wrong、box-dispute、box-view。這是經過限制的子集，不代表完整 Classic DICK 互動語法。其他 HTML 會顯示為文字。

單篇回答樣式

回答的閱讀樣式入口提供隔離預覽。在預覽使用 body、h2、table、blockquote 等選擇器；不會修改全域介面或原始回答。

安全與效能

CSS 沒有 JavaScript、檔案工具或模型權限。遠端資源、@import 及網路字體受安全政策阻擋。模型可以使用上述閱讀元件，不能修改全域 CSS。CSS 仍可遮蔽介面，請僅使用可信內容。

@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}

動畫優先使用 transform / opacity，避免多層大型模糊與無限陰影動畫。
