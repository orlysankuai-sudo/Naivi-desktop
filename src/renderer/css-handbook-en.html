Naivi / CSS handbook

Public Beta 4.0 · A Cygnus Automation Project

Apply and recover

Open Settings → Appearance → Custom application CSS. Save up to 20,000 characters locally. Press Ctrl + Shift + Backspace to clear custom CSS if you accidentally hide the interface. Do not hide confirmations, errors or access controls. Use only CSS you trust.

Design variables

VariablePurpose
--bg / --text / --mutedBackground, foreground and secondary text
--soft / --solid / --panel / --lineSoft surfaces, solid panels, glass panels and borders
--reading-font / --reading-size / --ui-sizeReading typeface, reading size and interface size

Some preferences set inline variables; use !important when overriding them. Accent selection uses five built-in palettes.

:root { --reading-size: 16px !important; }
html[data-theme="dark"] { --panel: rgba(20,24,32,.8) !important; }
.message-content { line-height: 1.9; }
.composer { border-radius: 20px; }

Stable hooks

.sidebar, .workspace, .workflow, .messages, .message-content, .composer, .node-markdown, .agent-orb and .settings-nav. The root exposes data-theme="dark|light" and data-layout="comfortable|focus|wide". Internal DOM structure may change between releases.

DICK Markdown

Use headings, tables, fenced code and blockquotes. Supported callout classes include tip-box, warning-box, and status-box box-question, box-topic, box-related, box-done, box-urgent. Scripts, event handlers and arbitrary HTML are rejected.

<div class="tip-box">A short, useful note.</div>

Accessibility and performance

Preserve visible focus and sufficient contrast. Prefer transform and opacity for animation; avoid full-window blur or constant layout animation. Respect reduced motion:

@media (prefers-reduced-motion: reduce) {
  .my-element { animation: none; transition: none; }
}

Reading preview

Per-answer reading CSS runs inside an isolated iframe. It cannot access the network, API keys or desktop tools, and does not rewrite the original answer. Application CSS changes presentation only; it grants no file or model permissions.
